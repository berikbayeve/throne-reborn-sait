# Throne Reborn Sait

Welcome to the Throne Reborn Sait project.

This repository is just getting started — expect the structure and docs to evolve as the project grows.

## Getting Started

```bash
npm install
npm run dev
```

Other commands: `npm run build`, `npm run lint`, `npm run format`. See [CLAUDE.md](./CLAUDE.md) for full project conventions.

Pushing to `main` auto-deploys the site to GitHub Pages.
