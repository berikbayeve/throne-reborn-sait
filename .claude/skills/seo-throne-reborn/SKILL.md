## Куда вставлять ключевые слова (on-page)

Для каждой страницы/секции сайта — не более 1-2 ключевых фраз на естественном языке, без переспама:

- **`<title>`** — включает основной + локацию: например «Throne Reborn — компьютерный клуб в Алматы».
- **Meta description** — 1 предложение с ценностным предложением + локация + призыв, до ~155 символов.
- **`<h1>`** — один на странице, содержит главный запрос естественно (не список ключей через запятую).
- **Первый абзац секции «О клубе»** — тоже естественно, не как список.
- **`alt`-атрибуты картинок** — описывают содержимое фото конкретно («интерьер компьютерного клуба Throne Reborn в Алматы», а не просто «фото»).
- **URL** — для одностраничника не критично, но якоря разделов (`#tariffs`, `#about`, `#contacts`) должны быть по-английски и понятны.

## Технический чек-лист (сделать в коде)

- [ ] `<title>` и meta description заданы в `index.html`, не дефолтные от Vite.
- [ ] Open Graph теги (`og:title`, `og:description`, `og:image`, `og:type=business.business`) — для красивого превью при шаринге в Instagram/WhatsApp/Telegram.
- [ ] Структурированные данные **schema.org LocalBusiness** (или `SportsActivityLocation`) с адресом, графиком работы 24/7, телефоном/соцсетями — помогает Google понять, что это локальный бизнес с конкретным адресом.
- [ ] `sitemap.xml` и `robots.txt` в `public/`.
- [ ] Один `<h1>` на странице, остальные заголовки — иерархично `<h2>`/`<h3>` по секциям (Hero не считается h1, если там просто лого — h1 обычно на теглайне/заголовке секции).
- [ ] Все картинки (`src/assets/photos`, иконки) — с `alt`, размеры оптимизированы (уже сделано — WebP + JPEG).
- [ ] Сайт грузится быстро — Vite это даёт по умолчанию, но проверить после добавления фото (Lighthouse/PageSpeed Insights, если доступно).
- [ ] Мобильная адаптивность — большинство посетителей смотрят сайт с телефона, особенно из Instagram.
- [ ] `canonical` тег на `https://berikbayeve.github.io/throne-reborn-sait/` (или на будущий домен, если купите свой).

## Локальное SEO (делает пользователь, не я)

Это регистрация в сервисах — требует доступа к аккаунту клуба, я не могу сделать это за пользователя:

- [ ] **2GIS** — карточка клуба с адресом, часами, фото, ссылкой на сайт.
- [ ] **Google Business Profile** — то же самое, критично для локальной выдачи Google.
- [ ] **Единообразие NAP** (Name, Address, Phone) — название/адрес/телефон должны быть написаны одинаково на сайте, в 2GIS, Google, Instagram — расхождения снижают доверие поисковика.
