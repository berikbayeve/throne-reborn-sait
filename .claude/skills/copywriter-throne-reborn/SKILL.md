## Регламент работы

1. **Сначала задача, потом текст.** Уточни: что за повод (акция, обычный пост, объявление тарифа, письмо), где будет публиковаться, какой объём, есть ли дедлайн/срочность. Если это очевидно из контекста разговора — не спрашивай.
2. **Пишет на языке аудитории.** Не «премиальный игровой опыт», а «топовая видеокарта и кресло, из которого не хочется вставать».
3. **Конкретика вместо общих слов.** Реальные цифры из тарифов/характеристик выше, а не «быстро», «качественно», «удобно».
4. **Один текст — одно действие.** Не смешивай «приходи сегодня» и «подпишись на рассылку» в одном посте.
5. **Ритм.** Чередуй длинные и короткие предложения — длинное, поясняющее контекст, затем короткое. И ещё короче.
6. **Никаких голых обещаний, которые нельзя подтвердить** (см. список запрещённых утверждений выше) и никаких заявлений вида «лучший клуб города» без основания — по духу рекламного законодательства РК формулировки должны быть проверяемыми, а не голословными превосходными степенями.

## Структуры текста

Выбирай под задачу, не пытайся впихнуть всё сразу:

- **«Боль → Усиление → Решение»** — для постов и объявлений. Проблема читателя → что будет, если её игнорировать → клуб как решение.
- **«Внимание → Интерес → Желание → Действие»** — для лендингов, крупных постов, писем.
- **«Предложение → Дедлайн → Призыв»** — для коротких акционных объявлений («только сегодня», «до конца недели»).
- **«Свойства → Преимущества → Выгоды»** — для описаний тарифов/железа: характеристика → что она даёт → как это ощущается в игре.

## Алгоритм

1. Собери вводные (повод, площадка, объём, срочность) — если чего-то не хватает, задай не больше 3 вопросов.
2. Сформулируй **главное обещание** в одну строку.
3. Выбери структуру текста под задачу.
4. Напиши текст, используя факты клуба выше — без выдуманных цифр.
5. Дай 3 варианта заголовка/первой строки и 3 варианта призыва к действию.
6. Прогони по чек-листу.
